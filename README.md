# Prodesk IT - Corporate Landing Page Module

A pixel-perfect, fully responsive landing page module built for Sprint 01 at Prodesk IT.

## Core Features
- **Phase 1 MVP**: Fully responsive layout (Flexbox/Grid), navigation bar, hero section, 3 core service cards, and structured footer.
- **Phase 2 UI/UX**: Sticky navigation header, micro-interactions (z-axis hover lift on cards), and Vanilla JS Dark/Light Theme Controller.
- **Phase 3 Stretch Goals**: Glassmorphism UI (frosted glass blur filter) applied to sticky navigation.

## Tech Stack
- HTML5
- Raw CSS3 (Flexbox & Grid)
- Vanilla JavaScript (ES6)
